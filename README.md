# Tic-Tac-Toe Console Game

A simple console-based Tic-Tac-Toe game built in C# using .NET Core.  
Players take turns entering row and column numbers (1 to 3) to mark their moves. The game detects wins, draws, and invalid inputs.

## Features

- Interactive console gameplay  
- 1-based row and column input  
- Win and draw detection  
- Input validation with error messages  

## Technologies

- C#  
- .NET Core Console Application  

## Prerequisites

- .NET SDK 6.0 or later installed on your machine
